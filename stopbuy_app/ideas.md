## 아이디어 A: "Analytical Dark" — 데이터 분석 대시보드

**Design Movement**: Dark Mode Data Intelligence (Bloomberg Terminal meets Modern SaaS)

**Core Principles**:
1. 데이터가 주인공 — 숫자와 게이지가 시각적 중심
2. 경고와 안도의 색채 대비 — 빨강/초록의 명확한 신호 체계
3. 정보 밀도 최적화 — 스크롤 없이 핵심 정보 파악
4. 신뢰감 있는 분석 도구 느낌

**Color Philosophy**:
- 배경: 딥 네이비 (#0A0E1A) — 전문성과 집중
- 주요 액센트: 앰버 (#F59E0B) — 경고와 주의
- 위험 표시: 코랄 레드 (#EF4444)
- 안전 표시: 에메랄드 (#10B981)
- 텍스트: 쿨 그레이 (#E2E8F0)

**Layout Paradigm**: 비대칭 분할 레이아웃 — 왼쪽 입력 패널(40%) + 오른쪽 결과 패널(60%)

**Signature Elements**:
1. 원형 후회 게이지 (SVG 애니메이션)
2. 위험도 배지 (high/medium/low 색상 코딩)
3. 카드형 대체상품 그리드

**Interaction Philosophy**: 즉각적 피드백, 실시간 진행 바, 결과 애니메이션 등장

**Animation**: 게이지 카운트업, 카드 스태거 등장, 진행률 바 슬라이드

**Typography System**: Pretendard (본문) + Space Grotesk (숫자/데이터)

## 아이디어 B: "Warm Editorial" — 소비자 매거진 스타일

**Design Movement**: Editorial Consumer Tech (Wirecutter meets Korean Shopping Magazine)

**Core Principles**:
1. 친근하고 읽기 쉬운 분석 결과
2. 상품 이미지 중심의 시각적 스토리텔링
3. 대체상품을 쇼핑 카탈로그처럼 표현
4. 구매 결정을 돕는 조언자 느낌

**Color Philosophy**:
- 배경: 따뜻한 오프화이트 (#FAFAF7)
- 주요 색상: 딥 테라코타 (#C2410C)
- 보조: 슬레이트 블루 (#475569)
- 강조: 골드 (#D97706)

**Layout Paradigm**: 잡지형 그리드 — 상단 히어로 + 하단 카드 갤러리

1. 대형 후회 점수 타이포그래피

## 아이디어 C: "Neo-Brutalist Alert" — 강렬한 경고 시스템

**Design Movement**: Neo-Brutalism + Warning System Design

**Core Principles**:
1. 경고의 시각적 충격 — 구매를 멈추게 하는 강렬함
2. 두꺼운 테두리와 강한 그림자
3. 과감한 타이포그래피 크기 대비
4. 흑백 + 강렬한 단색 액센트

**Color Philosophy**:
- 배경: 순백 (#FFFFFF) 또는 순흑 (#000000)
- 경고 액센트: 형광 옐로우 (#FACC15)
- 위험: 순수 레드 (#DC2626)
- 안전: 순수 그린 (#16A34A)

**Layout Paradigm**: 풀페이지 섹션 스택 — 각 섹션이 독립적인 강렬한 블록

**Signature Elements**:
1. 두꺼운 검정 테두리 카드
2. 대형 경고 아이콘
3. 스탬프 스타일 후회 레벨 배지

**Interaction Philosophy**: 클릭 시 강한 시각적 반응, 진동 효과

**Animation**: 바운스 등장, 스탬프 찍기 효과

**Typography System**: Black Han Sans (헤드라인) + Noto Sans KR (본문)
